# Animal Sounds Song — a kids' video, rendered from code

A 2:48, 1080p sing-along for toddlers: eight animals, a guessing game and a
closing chorus, with English subtitles burned into the picture and supplied
separately as an `.srt`.

Everything in the video is generated by this project — the characters are drawn
with canvas paths, the soundtrack and all eight animal voices are synthesised
with numpy, and the only third-party assets are two SIL OFL fonts. No stock
footage, no sample packs, nothing that can pick up a Content ID claim.

    ./render/build.sh          # → out/animal-sounds-song.mp4 (+ subtitles, thumbnail)
    ./render/build.sh --quick  # 960×540 preview, for iterating on the animation

The master renders at CRF 18, which is about 78 MB for the 2:48 cut. For a
smaller copy that is still fine to upload:

    ffmpeg -i out/animal-sounds-song.mp4 -c:v libx264 -crf 28.5 -preset medium \
           -pix_fmt yuv420p -c:a aac -b:a 160k -movflags +faststart \
           out/animal-sounds-song-compact.mp4     # ~26 MB

Open `web/index.html` in a browser to scrub through the animation with a
transport bar and per-scene jump buttons.

## How it fits together

`script.json` is the single source of truth: the scene list, durations, palettes
and every caption line. The animation, the subtitle file and the chapter
timestamps in the description are all derived from it, so they cannot drift
apart. Change a caption there and the picture, the `.srt` and the description
all follow.

    script.json ─┬─→ web/story.js ──→ frames ─┐
                 │                            ├─→ out/animal-sounds-song.mp4
                 ├─→ render/make_audio.py ────┘
                 └─→ render/make_subs.py  ──→ .srt + description + lyrics

| Path | What it does |
|---|---|
| `script.json` | Scenes, timings, palettes, caption cues |
| `web/core.js` | Easing, deterministic noise, shape primitives |
| `web/animals.js`, `web/animals2.js` | The eight characters |
| `web/stage.js` | Skies, hills, ponds, confetti, caption bar, banners |
| `web/story.js` | The director: `drawFrame(ctx, t)` |
| `web/index.html` | Canvas host — live preview *and* render target |
| `render/make_audio.py` | Synthesises the whole soundtrack |
| `render/make_subs.py` | `.srt`, lyric sheet, description with chapters |
| `render/render_video.mjs` | Frames → ffmpeg → MP4 |
| `render/make_thumbnail.mjs` | 1280×720 thumbnail |
| `youtube/UPLOAD.md` | Title, tags, upload settings, monetisation notes |

### Why it renders deterministically

`AnimalVideo.drawFrame(ctx, t)` is a pure function of `t`. There is no
`Math.random` and no wall-clock time in the draw path — the scattered clouds,
flowers and confetti all come from a hash of their index. The headless renderer
therefore produces exactly the pixels the browser preview shows, and re-running
the build gives the same video every time.

### Audio

`make_audio.py` builds the track on two buses. The band (bass, marimba-ish
melody, chord stabs, kick, shaker, bells) plays a I–V–vi–IV progression at
120 BPM, which is also the rate the characters bounce at. The animal calls sit
on a second bus, and the music ducks about 6 dB underneath them so the "MOO!"
always cuts through. Each call is synthesised — the moo is a pitch-glided sine
stack, the roar is a rasp of filtered noise over a low tone, the toot is a
lowpassed saw — and every call is levelled to the same peak so no animal gets
lost. The master lands at −14 LUFS / −1.5 dBTP, which is what YouTube targets.

## Requirements

    pip install numpy imageio-ffmpeg fonttools brotli
    npm install -g playwright        # plus a Chromium build

`build.sh` finds ffmpeg through `imageio-ffmpeg` or on `PATH`. Rendering all
5,040 frames takes about four minutes; the audio takes six seconds.

The code, artwork and music here are original. The fonts in `assets/fonts` are
Baloo 2 and Fredoka under the SIL Open Font License 1.1 (`assets/fonts/OFL.txt`),
